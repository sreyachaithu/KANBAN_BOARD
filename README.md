📌 Kanban Board

A simple and interactive Kanban Board web application built using React.js.
This application helps users manage and track tasks visually by organizing them into different stages such as To Do, In Progress, and Done.

🚀 Features

➕ Add new tasks

✏️ Edit tasks

❌ Delete tasks

🔄 Move tasks between columns

⚡ Real-time UI updates using React state

🎯 Simple and user-friendly interface

🛠️ Tech Stack

React.js

JavaScript (ES6)

HTML5

CSS3
